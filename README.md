# ApexPlanet Internship - Web Development

## Task 1: Responsive Multi-Page Static Website

This repository contains the submission for **Task 1** of my Web Development Internship at **ApexPlanet Software Pvt. Ltd.** The objective of this task was to design and build a clean, modern, and fully responsive multi-page static website using semantic HTML5 and custom CSS3 layouts.

---

## 🚀 Features Implemented

- **Multi-Page Navigation:** Seamlessly connects 4 core pages:
  - **Home:** Clean landing area highlighting key features with a modern grid setup.
  - **About:** Clear brand summary referencing corporate goals and talent mentorship.
  - **Services:** Structured display panels explaining core engineering capabilities.
  - **Contact:** Features an intake interactive form and an embedded responsive Google Maps widget.
- **Modern Layouts:** Fully designed using **CSS Flexbox** and **Grid** mechanisms instead of traditional float hacks.
- **Completely Responsive:** Integrated CSS Media Queries targeting seamless layouts across mobile, tablet, and desktop viewports.
- **Clean Document Object Structure:** Follows clean structuring using semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).

---

## 🛠️ Tech Stack Used

- **HTML5:** Structuring and layout definitions.
- **CSS3:** Custom variable definitions, media styling, Flexbox, and Grid modules.
- **Google Maps API (Iframe):** Integrated mapping location asset.
